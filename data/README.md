# Data catalogue

Rules: `data/raw/` is never edited; derived files are generated by a script into `data/processed/`. Add a row for every dataset before using it.

| Dataset | File(s) | Source / URL | Licence | Content | Use in the project | Known issues |
|---|---|---|---|---|---|---|
| Smoke detection (IoT sensors) | `raw/smoke_detection_iot.csv` | Kaggle "Smoke Detection Dataset" (confirm URL) | _(check)_ | TVOC, eCO2, H2, ethanol, PM, pressure, `Fire Alarm` label | Fire signature, model training | Many duplicated rows (differ only in temperature): split by session, do not shuffle randomly |
| Forest Fires (UCI) | `raw/forestfires.csv` | UCI Machine Learning Repository | _(check)_ | Meteorological indices and burnt area, Portugal | Context only | Not sensor time series |
| Castilla y León fire reports | `raw/incendios-forestales.csv` | Junta de Castilla y León open data | _(check)_ | Date, time, cause, municipality, area of each fire | Ignition-time statistics | Semicolon-separated, UTF-8 with BOM |
| Gas-sensor profiles (20 files) | `raw/Node_*_profile_*.csv` | _(who uploaded? source?)_ | _(unknown)_ | Gas-sensor resistance, temperature, humidity, `label_tag` | Candidate source of gas time series | **Meaning of `label_tag` undocumented**: do not use until clarified |
| Flux towers (Doñana, Cedar Bridge) | _(not in repo)_ | AmeriFlux / data portal | CC-BY-4.0 (Cedar Bridge) | CO2 flux, heat, radiation | Baseline of a forest without fire | Large: download by script, do not commit |
| NASA FIRMS | _(not in repo)_ | firms.modaps.eosdis.nasa.gov | NASA open data | Satellite hot spots | Fire statistics (frequency, intensity) | Acquisition time is the satellite pass, not ignition |

## Provenance and citations
Each source must be cited in the report with its licence.
